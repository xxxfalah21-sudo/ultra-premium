# Ultra Premium Telegram Bot

Bot Telegram webhook ready dengan fitur:
- UI anime aesthetic
- Anti Spam & Anti Link
- Auto Reply
- Database JSON
- Siap deploy ke Railway / Render

## Deploy
1. Buat Bot di Telegram lewat @BotFather  
2. Clone / Upload repo ini  
3. Isi ENV di Railway:
   - BOT_TOKEN
   - ADMIN_ID
   - DOMAIN
   - PORT
4. Start project dengan `npm install` lalu `npm start`
